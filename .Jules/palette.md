## 2026-08-06 - SPA Navigation and External Link Attributes\n**Learning:** In Docusaurus and similar SPA frameworks, applying `target="_blank"` to internal links (like in the announcement bar) is a common anti-pattern that breaks SPA routing and frustrates user navigation expectations. Updating it requires not only removing the attribute but also ensuring ARIA labels are updated to reflect that the link no longer opens in a new tab.\n**Action:** Always verify that internal links use appropriate routing (e.g., standard links without `target="_blank"` or framework-specific components) and that any associated accessibility labels accurately reflect the link's behavior.
